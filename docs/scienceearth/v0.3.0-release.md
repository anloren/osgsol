# osgSol Earth v0.3.0 - ScienceEarth G1

`v0.3.0` is the first formal, human-verifiable ScienceEarth G1 release. It is paired with the
immutable lineage tag `ScienceEarth-v0.3.0`. The plain `ScienceEarth` tag and `v0.2.0` remain on
the protected pre-science boundary commit `0e91c7c4b121d80b929d595ea711d3dd0833ee67`.

## User-visible changes

- AlphaEarth previews use the source CRS and affine transform instead of stretching a tile over
  its axis-aligned longitude/latitude bounds.
- Preview requests follow the viewed ground target and current view span, with the real footprint,
  longitude/latitude extent, and display resolution shown in the panel.
- The panel identifies the preview as a false-color embedding composite and documents the
  `R=A01`, `G=A16`, and `B=A09` channel mapping.
- The full-width year slider reloads the selected year when editing finishes and reports the
  resolved dataset identifier.
- Preview transparency keeps the basemap readable, a yellow border marks the real footprint, and
  the layer remains visible above terrain without leaking through the back of the globe.
- The camera target, existing photo workflow, and protected Earth behavior remain independent of
  ScienceEarth preview loading.

## Release verification

- ScienceEarth-off protected regression: 20/20 CTest tests passed.
- ScienceEarth preview regression: 1/1 CTest test passed.
- Live local-index smoke: 2018 resolved dataset `193510`; 2025 resolved dataset `195398`.
- Manual macOS verification at Mount Fuji, 20 km view height: the preview remained visible and
  reported approximately 21.9 km by 21.9 km coverage at 84 m/display pixel.
- Year interaction was verified from 2025 to 2018 with an automatic reload and a changed dataset
  identifier.
- The fixed desktop application produced a valid 1920 by 1080 offscreen render and exited through
  the in-app Quit control.

## Rollback

The immutable `v0.2.0` / `ScienceEarth` boundary remains the rollback point for the complete
pre-ScienceEarth behavior.
