# osgSol Earth UI 表面与交互证据清单

更新时间：2026-07-24

本清单是 UI/UE Goal 的范围合同。它区分正式主路径、故障回退路径、条件表面和
不会进入正式运行时的历史代码，并把“看得见”“能点击”“业务状态真的改变”
分开记录。以后新增可见控件时，必须同步补充对应的 A/B/M 级证据。

## 证据等级

- A：离屏真实 GL/RmlUi 运行时，使用正式生产绘制入口和真实鼠标、滚轮或键盘；
- B：逻辑、协议、绑定、源合同或包体测试；
- M：只能由用户在唯一桌面候选中验证的 Retina、在线服务、系统窗口和 Quit 行为。

|---|---|---|---|

## 正式 ImGui 交互

| 交互组 | 真实点击与状态断言 | 视觉/边界 |
|---|---|---|
| 顶栏 | 回到全球、收起/展开面板 | 三档视口、长路径、右侧动作不裁剪 |
| 模块轨 | 八模块逐项切换、再次点击收起 | 三档视口、选中态、无横向溢出 |
| 探索 | 常昼开关、太阳方向、对准相机、真实太阳互斥、跟随时钟、年月日键盘输入、UTC 小时、海洋、自动/手动曝光、大气强度 | 统一卡片、条件禁用态、滚动往返 |
| 跳转 | 纬度、经度、高度接受真实键盘输入；正式“飞过去”按钮改变相机位置 | 输入、提交与相机结果完整对应 |
| 书签巡游 | 记录、播放、停止、清空并核对操纵器状态 | 折叠段展开后仍可滚动到达 |
| 图层 | 搜索字段可输入；所有已注册预设真实进入 `LayerManager`；可见性和透明度真实改变状态 | 长来源、状态、透明度、空态、三档视口 |
| 实时/卫星/三维 | 每个模块只出现所属图层组，所属图层控件真实改变 `LayerManager` | 长详情卡和统一洞察轨道 |
| 任务 | 事件流、状态带开关真实改变状态；长事件流上下往返 | 状态带不压上下文托盘 |
| 设置 | 每个已注册运行参数真实改变；每个“默认”动作真实写回注册表 | 长设置列表和退出动作不裁剪 |
| Quit | 点击只发布 `QuitRequest`，不在 ImGui 渲染回调直接退出 | 无新 `.ips` 仍需 M |

上述正式抽屉控件由 `EarthControlUI::_auditCaptureControls` 在测试时记录实际
命中矩形；默认关闭，不改变桌面运行时行为。测试必须先证明控件完整位于抽屉裁剪区，
再向其中心发送鼠标移动、按下和释放，不能再用“截图中出现过”替代可操作性。

| 交互组 | A 级覆盖 |

RmlUi 的可见按钮必须具有稳定 ID 并绑定 presenter；文档合同测试会拒绝无 ID、
无监听器或内容与活动标签不一致的控件。

## AI 与洞察表面

| 表面 | A 级覆盖 | M 级保留 |
|---|---|---|
| AI 命令栏 | 历史展开/收起；模板打开/外点关闭；输入并发送精确文本；模板首项真实定位并提交精确提示词 | Gemini 真调用 |
| 照片 | 正式按钮可达；提交“当前视角”精确请求，不移动相机、不复用旧图 | 真图片生成、文件查看 |
| 视频 | 起点、终点、行内取消、确认弹窗确认/取消均经过真实点击并发布对应请求 | 真视频生成、文件播放 |
| AI 图表 | 折线、柱状、环图、统计卡；坐标、单位、图例和长标签 | 在线数据语义 |
| 媒体与任务 | 照片、视频、生成进度、长任务标题 | 文件打开与真实生成 |
| 洞察透镜 | 多标签、长内容、上下滚动、条件卡与抽屉/命令栏互不重叠 | 真实长在线详情 |

AI 的 A 级媒体交互使用仅在 `OSGSOL_UI_AUDIT_HOOKS` 测试构建中存在的请求
截获器。它仍然点击正式生产按钮、读取正式命中矩形并验证请求种类与提示词，但不会
访问网络、截图、生成文件或打开系统应用；正常生产构建不包含这些审计字段。

## 不允许自动执行的外部副作用

以下动作属于正式 UI，但自动化不得为了“点击覆盖”制造外部窗口、网络或桌面干扰：

- “打开来源”启动浏览器；
- Gemini、照片、视频和跨数据源 research 的真实外部执行；
- 打开或前置 `/Users/USER/Desktop/osgSol Earth.app`；
- 应用内 Quit 后的 macOS 异常报告检查。

它们必须由协议/状态合同和 M 级用户验收共同覆盖。自动化仍会验证按钮的布局、
可见条件、精确请求对象、精确提示词和所有不产生外部副作用的前置状态。

## 当前唯一人工门槛

1. 在 `/Users/USER/Desktop/osgSol Earth.app` 检查 Retina 字体与真实地图背景；
2. 抽查科学在线结果、3D Tiles、实时数据和 AI 真调用；
3. 从应用内正常退出，确认没有新的匹配 `.ips`；
4. 通过后才允许 Tag、同步和结束 Goal。
