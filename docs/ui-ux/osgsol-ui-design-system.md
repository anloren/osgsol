# osgSol Earth UI 设计系统

日期：2026-07-24

版本：0.1，Goal 实施契约

## 产品表达

设计方向命名为 **Obsidian Survey / 深夜测绘仪**。

它不是常见的“蓝青色科技大屏”，而是一套服务于地球观察、空间定位和科学
证据的暗色制图仪器：

- 温暖石墨黑承载工具，避免纯黑与白底造成突兀反差；
- 测绘青只用于选中、空间目标、主操作和图表主序列；
- 赭红只表示当前模块与需要明确注意的导航状态；
- 测量金表示实际覆盖、警告和科学比较基准；
- 地图保持画面主角，面板边界清楚但不浮夸。

## 设计依据

- NASA Worldview 把图层、时间和地图上下文组织成一个连续的地球观测任务：
  <https://worldview.earthdata.nasa.gov/>
- NASA Earthdata 对 Worldview 的定位与能力说明：
  <https://www.earthdata.nasa.gov/data/tools/worldview>
- Esri Dashboard 的主题机制说明了地图、图表和面板需要统一主题：
  <https://doc.arcgis.com/en/dashboards/latest/get-started/change-theme.htm>
- Dribbble 地理空间产品案例用于比较视觉密度与卡片组织，不作为直接复制模板：
  <https://dribbble.com/search/geospatial-dashboard>

Figma Community 在本次调研环境中被 `robots.txt` 阻止，未把不可见模板当成
设计证据。

## 信息架构

### 常驻层

1. 顶部：当前位置、路径、全局动作、系统状态。
2. 左侧：固定模块轨。
3. 左侧抽屉：当前模块的任务流；与模块轨无透明缝。
4. 中央：地球主画布。
5. 底部中央：紧凑 AI 命令栏；历史和模板按需展开。
6. 底部：当前上下文与状态；只显示真正需要常驻的信息。

### 按需层

- 详情卡：与对象绑定，可关闭，可重新打开；
- 科学报告：中央可移动、最小化、关闭和恢复；
- 确认层：只用于不可逆动作；
- 帮助层：解释数据、单位和限制，不永久占据主任务空间。

## 几何与间距

- 基础间距单位：4 px；
- 面板内容内边距：12/16 px；
- 相邻卡片间距：10/12 px；
- 窗口边界：1 px；
- 输入和按钮最小高度：36 px；
- 模块项最小高度：44 px；
- 卡片圆角：4 px；
- 输入、按钮圆角：3 px；
- 浮动报告圆角：6 px；
- 停靠面板不使用造成地图漏缝的外圆角或透明间距。

## 组件规则

### 模块轨

- 一行一个模块，图标与短标签同时存在；
- 当前模块使用赭红底、测绘青标记和主文本；
- hover 与 selected 明确区分；
- 不使用仅凭颜色难以分辨的圆点。

### 抽屉

- 与模块轨和顶部状态栏无缝停靠；
- 标题区、可滚动内容区、固定操作区三段式；
- 滚动条位于内容区内部，不在地图上形成独立透明通道；
- 所有卡片宽度来自容器，不写死 290/320/360 px。

### 字段与菜单

- 下拉菜单有完整字段边界、文本区域和一个箭头；
- 箭头不以空白方块或竖线出现；
- 菜单展开项不重叠，当前项、hover 和 disabled 状态明确；
- 年份使用两个数字字段与文字摘要；没有真实拖动能力时不显示滑杆。

### 主操作

- 每个任务面板只有一个同层级主操作；
- 禁用时显示原因；
- 进行中在原位变为阶段、进度和取消，不生成第二个竞争按钮；
- 危险操作不与关闭、最小化并列为同样视觉权重。

### 浮动报告

- 标题栏提供拖动区域、最小化、更多、关闭；
- 动作按钮始终完整可见；
- 内容区按标签切换，单独滚动；
- 概览地图使用真实最终合成画面，不用白底或空占位；
- 最小化不删除结果，关闭保留结果，删除需确认。

### 洞察透镜

- 航班、卫星、要素、事件和 AI 结果只进入一个右侧窗口，不再叠出多列浮窗；
- 多个来源使用标签切换，窗口宽度固定在洞察轨道；
- 高度由当前标签的实测内容决定，但不得越过 AI 命令栏和上下文区；
- 超长内容必须出现真实纵向滚动范围，并且可以到底后返回顶部；
- 标签、副标题和卡片正文必须在固定宽度内换行，不得反向撑大窗口。

## 科学图表规范

每张趋势图必须同时提供：

1. 指标中文/官方名；
2. 单位与时间聚合方法；
3. X 轴首年、中间年、末年；
4. Y 轴最小、中点、最大值和单位；
5. 缺测年份说明；
6. hover 预览与 click 固定年份；
7. 最小、最大、均值、首末变化和线性趋势；
8. 不同单位绝不共用一个 Y 轴。

主序列使用测绘青，固定年份使用测量金，缺测使用虚线/空点与文字，不只改变
颜色。坐标文本置于图表外层 DOM，图形元素只负责数据线和命中测试。

## 响应式规则

| 视口 | 行为 |
|---|---|
| ≥ 1600 px | 完整抽屉、完整报告、AI 单行动作 |
| 1200–1599 px | 报告收窄，次要标题缩短，保持地图边界 |
| 1024–1199 px | 紧凑报告，AI 动作可换到第二行 |
| 高度 ≤ 640 px | 抽屉固定操作区收紧，报告高度受 AI 栏上边界约束 |

任何分辨率下：

- 主操作、关闭、返回和取消必须可见；
- 地图至少保留 30% 可见宽度；
- 不得出现横向溢出；
- 滚动到底后必须能滚回；
- 长中英文和单位符号不能越界。

## 状态语法

| 状态 | 表达 |
|---|---|
| 未设置 | 次要文本 + 明确下一步 |
| 可执行 | 主操作高亮 |
| 加载 | 阶段名 + 进度/不确定进度 + 取消 |
| 成功 | 绿色状态文字 + 可见结果入口 |
| 部分结果 | 测量金 + 明确缺少项 |
| 失败 | 错误位置就地红色说明 + 重试 |
| 禁用 | 降低对比度 + 禁用原因 |
| 警告 | 测量金，不用满屏水印 |

## 工程验收

- 源合同测试：token、控件语义、Rml 文档结构；
- 真实布局测试：RmlUi 元素边界、点击、滚动、菜单和溢出；
- 离屏 GL：工作台、报告、图表和最终地图快照；
- ImGui 布局：三档视口、动作宽度、窗口不越界；
- 离线回归：科学、AI、地图、三维、实时与退出路径；
- 正式包：只更新 `/Users/USER/Desktop/osgSol Earth.app`；
- 自动化不启动该 App；最终由用户手动检查可视状态与正常 Quit。
