## 跨表面不可回退门禁

1. ImGui 与 RmlUi 使用同一 Obsidian Survey token；
2. 正常字号文本在最浅常用表面上对比度至少 4.5:1；
3. 停靠面板之间不允许透明地图缝；
4. 交互控件必须有 hover、focus、disabled、busy、error 或 success 的明确状态；
5. 装饰元素不能伪装成滑杆、按钮或可操作标签；
6. 数据源选择必须同步标题、说明、参数、方法和提交目标；
7. 模块只能接收所属图层组，不能残留上一模块内容；
8. 1024×576、1440×900、2048×1152 均不得出现边缘裁剪或横向溢出；
9. 滚动区域必须可下滚、可返回，并显示与容器连续的滚动条；
10. 自动化不得启动或前置桌面候选，最终可见观感和正常 Quit 由用户手测确认。

## 证据等级

- A：真实离屏 GL/布局运行时，包含点击、滚轮、键盘、像素或几何断言；
- B：纯逻辑/合同测试，证明状态、模块隔离、token、文档结构或打包契约；
- C：构建、全量回归、依赖、签名与包体审计；
- M：只能由用户在唯一桌面正式候选上完成的真机验收。

全产品交付至少需要 A+B+C 全绿；Goal 只有在 M 也通过后才能结束并进入 Tag/同步。
