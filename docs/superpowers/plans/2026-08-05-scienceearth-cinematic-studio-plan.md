# ScienceEarth 时空影像工作台实施计划

> 日期：2026-08-05
> 范围：图像与视频生成；不改地球渲染、地形、3D Tiles、科学数据加载和退出链路。

## 产品目标

把底部“照片 / 视频”两个一次性按钮升级为统一的“时空影像工作台”：用户始终从当前可见地球画面出发，选择时代、当地时间、视觉媒介或视频运镜，再提交一份可审计、不可串片的生成请求。

核心场景包括：

- 1920 年香港维多利亚港、当地晚上 7 点、泛黄档案照片；
- 澄江寒武纪生态的科学重建；
- 当前视角的一键超写实航拍漫游；
- 360 度环拍、俯冲、升降揭示、横移与两点穿越；
- 同一镜头的超写实、纪录片、档案、动漫等视觉表达。

## 不可破坏合同

1. 当前帧是几何锚点：每次提交都重新冻结当前相机、投影、视口和画面中心，不得因生图或视频而移动、缩放或重置相机。
2. 每次生成独立：新请求拥有唯一 ID 和独立输入快照；默认不携带旧产物、旧地点或旧参考图。
3. 科学与创意分层：地点、相机、地质年代、历史时期和可验证环境事实进入证据层；风格、媒介和情绪进入创意层；不得把推测写成实测或档案事实。
4. 历史与深时重建必须显式标注“重建”和不确定性，加入时代错置防护；寒武纪场景不得出现人类、现代建筑、现代船只或现代植被组合。
5. 视频首帧必须来自本次当前视角的生成图；Nano Banana 2 负责图像，视频运镜由当前视频 provider（Veo / Omni）承担。
6. 现有照片、两点巡航、离线 fake、作业卡、HUD 隐藏和错误回传路径继续可用。

## 交互设计

底部保留两个轻量入口：“图像”和“视频”。点击后打开同一个工作台弹窗，而不是立即计费提交。

工作台稳定结构：

1. **当前视角**：显示经纬度、高度、方向、俯视角、视场和“生成不会移动镜头”状态。
2. **创作意图**：多行提示词，允许用户补充地点细节、季节、天气、叙事或禁用内容。
3. **时空**：时代预设（当前 / 1920 年代 / 寒武纪 / 自定义）和当地时间预设（黎明 / 正午 / 19:00 / 深夜 / 自定义）。
4. **表现**：科学写实、超写实、档案泛黄、纪录片、电影、动漫；默认值以清晰按钮显示，不依赖隐藏状态。
5. **视频运镜**：超写实航拍、360 环拍、俯冲、升降揭示、横移、两点穿越。除“两点穿越”外都从单个当前首帧生成。
6. **科学边界**：只有历史 / 深时 / 强推测请求时展开，列出证据依据、不确定性、时代错置防护和“生成内容不是观测记录”。
7. **提交**：唯一主按钮“从当前视角生成”；旁边显示 provider、预计时长/费用边界和取消能力。

必须实现 idle、editing、capturing、generating、success、failed、cancelled 全部状态；加载期间不阻塞退出或地图交互。

## 实现顺序

### 1. 纯数据合同与提示词（TDD）

- 新增 `ai_cinematic_request.h`，定义图像/视频类型、时代、当地时间、风格、运镜、科学重建级别和用户提示词。
- 请求只能从不可变 `PhotoCaptureRequest` 建立；构造失败时不允许提交。
- 历史、寒武纪、视频运镜提示词采用“几何事实 / 科学证据与假设 / 创意指令 / 禁止项”四段式。
- 预设映射为稳定枚举和可测试标签，不让 UI 直接拼自由文本。

### 2. Provider 参数

- 图像默认模型更新为官方 Nano Banana 2：`gemini-3.1-flash-image`，继续允许 `EARTH_AI_IMAGE_MODEL` 覆盖。
- 请求明确携带图像响应模态；根据当前视口选择最接近的长宽比，质量默认 2K，严谨重建可选 4K（以 provider 支持为准）。
- 视频继续使用已有 Veo / Omni 路径；首帧是本请求自己的 Nano Banana 2 图像。运镜预设转换为 provider 可理解的摄影机运动语法。

### 3. 媒体状态机接线

- `startPhotoJob` 接收结构化工作台设置，并在快门边界冻结成不可变请求。
- 单帧视频预设新增“当前视角起步”路径；两点穿越保留原 A/B 路径。
- 文件名继续使用时间戳 + job ID；所有 worker 捕获值类型请求，不读取随后变化的 UI 状态。

### 4. 工作台 UI

- 把“照片 / 视频”改成打开工作台的入口。
- 使用统一暗色设计令牌、明确分组、真实按钮、可读换行和滚动区域。
- 默认预设直接可见；帮助内容按需出现，不以长段常驻文字占据界面。
- 扩充 UI 审计快照，覆盖入口、预设、提示词、提交、取消和弹窗边界。

### 5. 验证

- 单元测试：请求独立、当前视角锁、历史重建、寒武纪重建、六类运镜、模型默认值和 JSON 请求。
- 离线媒体测试：图像 fake、视频 fake、失败注入、连续两次生成不串图。
- UI 审计：1280×720、1440×900、2048×1152 下无溢出、关键控件可点击、滚动与取消可达。
- 全套 Science ON/OFF 非窗口离线回归。
- 不启动桌面 App；运行时视觉验收留给用户手测版本。

## 本阶段完成边界

本阶段完成“结构化请求 + 提示词 + provider + 工作台 + 离线回归”。真实云端输出的历史准确性和视频质量必须由真机生成样本复核，不能用静态测试冒充已验收。

## 2026-08-05 实施与验证记录

- 已完成统一时空影像请求合同、当前相机几何锁、独立请求 ID、历史/深时重建边界和六类视频运镜提示词。
- 图像 provider 默认更新为 `gemini-3.1-flash-image`，显式提交图像模态、视口最接近长宽比和 2K 默认质量；仍保留环境变量覆盖。
- 图像与视频均进入同一工作台，提供提示词、恢复默认、时代、当地时间、风格和运镜按钮；图像首屏完整可见，视频实际溢出时显示可拖动滚动条。
- 一键航拍、360 环拍、俯冲、升降揭示和横移只冻结本次当前首帧；两点穿越继续使用独立 A/B 快照。确认界面明确区分两种流程，网络计费请求只在确认后发出。
- `osgVerse_EarthExplorer` 在 Science ON/OFF 两个 Release 构建中通过；图像/视频提示词与请求单测、媒体队列测试和无窗口 CGL 产品 UI 点击审计通过。
- Science ON 非窗口离线回归：82/82；Science OFF 非窗口离线回归：33/33；`git diff --check` 通过。
- 未启动或聚焦桌面 App，未创建监听端口，未改 macOS 设置，未打包、签名、打 tag 或推送。
